# tareas-ensambla

Repositorio creado para las tareas del curso CI0118 de la Universidad de Costa Rica.

## Tarea 1: El juego de la vida de Conway

Esta tarea implementa el juego de la vida de Conway (Conway's Game of Life) en lenguaje ensamblador para una arquitectura x86. Para la interfaz gráfica se usó SDL2. El propósito de esta tarea es familiarizarse con la programación el lenguaje ensamblador y cómo esto se puede conectar con lenguajes de alto nivel.

## Tarea 2: Prototipo de aplicación de refugio animal

Esta segunda tarea es un prototipo de lo que sería un módulo de registro e inicio de sesión. El propósito de esta tarea es familiarizarse más con bibliotecas gráficas de desarrollo de aplicaciones de escritorio, como GTK o Qt.
